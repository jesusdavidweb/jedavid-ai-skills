# Telemetry

Use correlation/request IDs across boundaries. Log authentication/authorization failures, high-risk actions, application errors and important state changes without credentials/tokens/payment data. Protect security/audit logs from unauthorized modification/deletion. Metrics should expose rate/errors/latency/saturation where meaningful; traces help distributed failure/latency diagnosis but need sampling and sensitive-attribute controls. Alert on actionable symptoms rather than noisy low-value events.
