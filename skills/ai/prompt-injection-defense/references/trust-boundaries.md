# Prompt-Injection Trust Boundaries

Treat user messages/files, websites/search, emails/tickets/issues, databases/documents, external tool/MCP outputs and model-generated intermediate text as untrusted unless explicitly established otherwise. Combine instruction/data separation, input/output validation, least privilege, deterministic policy checks and adversarial testing. No prompt text alone guarantees resistance to hostile content.
