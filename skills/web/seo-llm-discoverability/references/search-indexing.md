# Search Indexing

Canonical signals include redirects, `rel=canonical`, sitemap inclusion and content similarity; a declared canonical is a preference, not an absolute command. Audit indexable 200 responses, robots controls vs page-level `noindex`, canonical consistency, sitemap membership, redirect chains, hreflang reciprocity and parameter/filter strategy. Important content should exist in rendered HTML. Do not rely on `robots.txt` to remove an already-known URL from an index.
