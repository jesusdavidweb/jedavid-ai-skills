# Structured Data and LLM Discoverability

Structured data must describe visible content; do not fabricate ratings, authors or entities only for markup. Keep identifiers and names consistent. For AI discovery, prefer stable crawlable URLs, explicit factual prose, meaningful headings/links and useful provenance. Treat `llms.txt` and similar emerging conventions as optional discovery aids, not substitutes for accessible HTML, sitemaps, robots controls or structured data. Never hide text solely for AI systems.
