# OWASP ASVS Baseline

OWASP ASVS 5.0.0 is the current stable ASVS release. Use it as a structured set of verifiable application-security requirements and cite requirement IDs when a finding maps cleanly to one.

Do not claim ASVS compliance from a lightweight code review. State the scope and which controls were actually verified. Combine ASVS with threat modeling and technology-specific evidence.
