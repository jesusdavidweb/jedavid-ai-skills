# Product UX Audit
## Workflow
1. Define the user's goal and critical path before commenting on visual polish.
2. Walk each state including empty, loading, success, failure, validation and permission cases.
3. Evaluate information hierarchy, action clarity, feedback, error recovery and cognitive load.
4. Check accessibility and mobile/responsive behavior as product requirements, not separate polish.
5. Distinguish evidence-backed usability problems from subjective visual preferences.
6. Rank findings by user impact, frequency and implementation effort.
7. Recommend the smallest flow/design changes that remove the most friction.
## Output
Journey map, prioritized findings, affected screens/states, recommendations and validation ideas.
