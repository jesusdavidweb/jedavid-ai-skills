# Affiliate Content Platform
## Workflow
1. Define commercial entities: products, variants, brands, merchants, offers, categories, editorial content and affiliate links.
2. Separate canonical product data from merchant-specific price/availability/URL data.
3. Track source, fetched_at and confidence/quality for external product data; never silently present stale or inferred pricing as live.
4. Normalize identifiers to deduplicate products across feeds while retaining source provenance.
5. Build category/product/editorial pages around genuine user intent and useful comparison context rather than thin autogenerated pages.
6. Implement affiliate disclosures clearly and preserve tracking parameters without polluting canonical URLs.
7. Measure outbound clicks, merchant conversions when available, content-assisted journeys and data freshness.
8. Design ingestion with rate limits, retries, incremental sync and reconciliation.
## Output
Data model, ingestion architecture, SEO/content architecture, attribution plan and data-quality risks.
