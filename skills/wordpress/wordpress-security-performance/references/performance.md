# WordPress Performance

Measure TTFB/cache-hit behavior, PHP worker saturation, object/page/opcode caches, autoloaded options, slow/large tables, WP-Cron/Action Scheduler backlog and frontend JS/fonts/images. WooCommerce cart, checkout, account and personalized routes need intentional dynamic-cache exclusions. Prove table/option ownership before cleanup. Prefer field Core Web Vitals when available; lab tools diagnose rather than replace RUM.
