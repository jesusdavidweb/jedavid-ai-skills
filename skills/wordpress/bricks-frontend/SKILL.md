# Bricks Frontend
## Workflow
1. Inspect global styles, variables, templates, conditions and existing component conventions before adding local overrides.
2. Prefer reusable classes/variables over per-element styling.
3. Keep custom code isolated, versionable and dependency-aware.
4. Use semantic HTML and accessible interactions even when builder defaults make shortcuts easy.
5. For WooCommerce, preserve dynamic hooks/state and test guest/account/cart/checkout templates.
6. Test responsive behavior at content-driven breakpoints and real device widths.
7. Measure frontend impact of animations, scripts, fonts and background media.
